# Musterlösungen

Dieser Ordner gehört zum Content-Repo und nicht in die Übungs-Repos, die Lernende forken.

`python3 selbsttest.py` prüft für jede Challenge zwei Dinge: Das unbearbeitete Übungs-Repo fällt durch, und
mit der Musterlösung besteht es. So fällt sofort auf, wenn eine Übung und ihre Prüfung auseinanderlaufen.
Der Selbsttest gehört in die Pipeline des Content-Repos.
