# AGENTS.md

## Befehle

- Tests: `python3 -m unittest discover tests`
- Prüfung der Abgabe: `python3 pruefung/pruefe.py`

## Aufbau

- `bestellung/`: Code des Bestell-Dienstes
- `tests/`: Tests des Projekts
- `daten/`: Schema und Beispielbestellung
- `abgabe/`: Kriterien und Plan zur Aufgabe
- `pruefung/`: Prüfskript der Challenge

## Grenzen

- `daten/schema.json`, `pruefung/` und `.gitlab-ci.yml` nicht ändern.
- Keine Tests löschen oder abschwächen.
- Nur die Python-Standardbibliothek.
