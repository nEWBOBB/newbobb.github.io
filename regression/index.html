01 · Das Modell

Eine Gerade raten

Stell dir vor, du notierst für ein paar Wohnungen die Größe und die Miete. Die Punkte streuen, aber man sieht einen Trend: größer heißt teurer. Diesen Trend wollen wir als Formel haben, damit wir für eine neue Wohnung die Miete vorhersagen können.

Das einfachste Modell dafür ist eine Gerade. Sie hat genau zwei Stellschrauben:

ŷ = m · x + b m ist die Steigung, b der Achsenabschnitt. ŷ („y-Dach“) ist die Vorhersage für die Eingabe x.

„Lernen“ heißt hier nichts anderes, als m und b so zu wählen, dass die Gerade gut zu den Punkten passt. Probier es zuerst von Hand.

MerkeEin Modell ist eine Formel mit Stellschrauben. Lernen heißt, die Stellschrauben an Beispieldaten anzupassen.

Dreh an Steigung und Achsenabschnitt, bis die Gerade gut passt. Tipp auf die Fläche, um Punkte hinzuzufügen, zieh Punkte zum Verschieben, tipp einen Punkt an, um ihn zu löschen.

02 · Die Verlustfunktion

Den Fehler messen

„Passt gut“ ist zu ungenau für einen Computer. Wir brauchen eine Zahl. Dazu schauen wir uns für jeden Punkt den Abstand zur Geraden an, das Residuum: wie weit lag die Vorhersage daneben?

Manche Abstände sind positiv, manche negativ. Damit sie sich nicht gegenseitig aufheben, wird jeder Abstand quadriert. Der Durchschnitt dieser Quadrate ist der mittlere quadratische Fehler, kurz MSE.

MSE = (1/n) · Σ (yᵢ − (m·xᵢ + b))² Schalte oben „Fehler als Quadrate“ ein: Der MSE ist genau die durchschnittliche Fläche dieser Quadrate.

Das Quadrieren hat einen Nebeneffekt: Große Fehler zählen überproportional. Ein Punkt, der doppelt so weit daneben liegt, kostet viermal so viel. Deshalb reißen Ausreißer die Gerade stark zu sich.

Jetzt kann man das Problem umdrehen: Jede Kombination aus m und b hat einen Fehlerwert. Zeichnet man alle auf, entsteht eine Landschaft. Rechts ist sie zu sehen: dunkel heißt kleiner Fehler. Irgendwo liegt der tiefste Punkt. Den suchen wir.

MerkeDie Verlustfunktion macht aus „passt gut“ eine Zahl. Lernen wird damit zur Suche nach dem tiefsten Punkt einer Landschaft.

03 · Gradientenabstieg

Bergab lernen

Bei zwei Stellschrauben könnte man die ganze Landschaft abrastern. Ein großes Sprachmodell hat aber Milliarden davon. Dafür gibt es einen Trick, der überall im Machine Learning steckt: den Gradientenabstieg.

Stell dir vor, du stehst im Nebel auf einem Hügel und willst ins Tal. Du siehst nichts, aber du spürst, in welche Richtung der Boden abfällt. Also machst du einen kleinen Schritt bergab. Und noch einen. Und noch einen.

Die „gefühlte Neigung“ ist die Ableitung des Fehlers nach m und nach b. Für den MSE lässt sie sich direkt hinschreiben:

∂MSE/∂m = −(2/n) · Σ xᵢ · (yᵢ − ŷᵢ)
∂MSE/∂b = −(2/n) · Σ (yᵢ − ŷᵢ) Danach: m ← m − α · ∂MSE/∂m und b ← b − α · ∂MSE/∂b. α ist die Lernrate.

Die Lernrate ist die Schrittlänge. Zu klein: Es dauert ewig. Zu groß: Man springt über das Tal hinaus, landet auf der anderen Seite noch höher und schaukelt sich auf, bis alles explodiert. Probier beides aus.

MerkeGradientenabstieg: Neigung ausrechnen, kleinen Schritt bergab machen, wiederholen. So lernen auch die größten neuronalen Netze.

Der Fehler wird beim Training mit jedem Schritt größer statt kleiner. Was ist die wahrscheinlichste Ursache?

04 · Kleinste Quadrate

Die exakte Lösung

Für die Gerade gibt es eine Abkürzung. Weil die Fehler-Landschaft eine glatte Schüssel ist, liegt das Minimum genau dort, wo beide Ableitungen null sind. Löst man das auf, fallen zwei Formeln heraus, die schon Gauß und Legendre um 1805 benutzt haben:

m = Σ (xᵢ − x̄)(yᵢ − ȳ) / Σ (xᵢ − x̄)²
b = ȳ − m · x̄ x̄ und ȳ sind die Mittelwerte. Die beste Gerade läuft immer durch den Schwerpunkt (x̄, ȳ).

Wie gut die Gerade insgesamt erklärt, misst R²: 1 heißt, alle Punkte liegen exakt drauf; 0 heißt, die Gerade ist nicht besser als einfach immer den Mittelwert zu raten.

Warum dann überhaupt Gradientenabstieg? Weil die exakte Formel nur für so einfache Modelle existiert. Für ein neuronales Netz gibt es keine. Bergab gehen funktioniert dagegen immer.

regression.js · komplett, ohne Bibliothek
function fit(xs, ys) {
  const n = xs.length;
  const mx = xs.reduce((a, x) => a + x, 0) / n;
  const my = ys.reduce((a, y) => a + y, 0) / n;
  let num = 0, den = 0;
  for (let i = 0; i < n; i++) {
    num += (xs[i] - mx) * (ys[i] - my);
    den += (xs[i] - mx) ** 2;
  }
  const m = num / den;
  return { m, b: my - m * mx };
}

// Dasselbe mit Gradientenabstieg
function train(xs, ys, lr = 0.01, steps = 1000) {
  let m = 0, b = 0;
  const n = xs.length;
  for (let s = 0; s < steps; s++) {
    let gm = 0, gb = 0;
    for (let i = 0; i < n; i++) {
      const err = ys[i] - (m * xs[i] + b);
      gm += (-2 / n) * xs[i] * err;
      gb += (-2 / n) * err;
    }
    m -= lr * gm;
    b -= lr * gb;
  }
  return { m, b };
}

MerkeFür die Gerade gibt es eine Formel. Für fast alles andere im Machine Learning nicht, da bleibt nur der Gradientenabstieg.

Hier wird immer die exakte Gerade berechnet. Zieh einen Punkt weit nach oben und sieh, wie stark ein einzelner Ausreißer alles verbiegt.
