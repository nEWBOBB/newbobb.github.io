01 · Der Baustein

Ein Neuron

Ein künstliches Neuron ist erstaunlich simpel. Es bekommt Zahlen herein, multipliziert jede mit einem Gewicht, zählt alles zusammen und addiert einen Bias. Das ist fast die Gerade aus der Regression.

z = w₁·x₁ + w₂·x₂ + b    a = σ(z) = 1 / (1 + e⁻ᶻ) σ, die Sigmoid-Funktion, presst jede Zahl auf einen Wert zwischen 0 und 1: eine Wahrscheinlichkeit für „blau“.

Die Fläche rechts zeigt für jeden Ort, was das Neuron sagen würde: blau oder orange. Die Grenze dazwischen ist immer eine gerade Linie. Für manche Daten reicht das. Lade aber mal die XOR-Daten, bei denen Blau in zwei gegenüberliegenden Ecken liegt: Keine Einstellung der Welt trennt sie mit einer Geraden.

Das war 1969 ein echter Schock. Marvin Minsky und Seymour Papert bewiesen genau das, und die Forschung an neuronalen Netzen schlief für über ein Jahrzehnt fast ein.

MerkeEin Neuron = gewichtete Summe + Aktivierungsfunktion. Allein kann es nur mit einer Geraden trennen.

Stell die Gewichte so ein, dass alle blauen Punkte im blauen Bereich liegen. Oder lass das Neuron selbst lernen.

02 · Versteckte Schichten

Ein ganzes Netz

Der Ausweg: Neuronen hintereinanderschalten. Die erste Schicht zieht ein paar Geraden, die nächste kombiniert sie. Dazwischen sitzt eine nicht-lineare Aktivierung wie tanh oder ReLU. Ohne sie wäre das ganze Netz wieder nur eine einzige Gerade, egal wie viele Schichten es hat.

Unten trainiert ein echtes Netz, von Hand programmiert, live in deinem Browser. Links siehst du, wie es die Fläche einfärbt, rechts das Netz selbst: blaue Verbindungen sind positive Gewichte, orange negative, die Dicke zeigt die Stärke. Probier die Spirale mit nur zwei Neuronen, dann mit acht in zwei Schichten.

03 · Merkmale

Was die Neuronen sehen

Jedes versteckte Neuron ist für sich wieder nur eine kleine Entscheidungsfläche. Rechts sind sie alle einzeln zu sehen, für das Netz aus Kapitel 2. In der ersten Schicht sind es immer Geraden mit weichem Übergang. In späteren Schichten entstehen daraus Ecken, Bögen und Inseln.

Das ist die Grundidee des Deep Learning: Frühe Schichten lernen einfache Merkmale, spätere setzen sie zu immer komplexeren zusammen. In einem Bilderkennungs-Netz sind das zuerst Kanten, dann Ecken, dann Augen, dann Gesichter. Niemand hat das vorgegeben, es entsteht beim Training von selbst.

MerkeVersteckte Schichten bauen aus einfachen Merkmalen komplexe. Deshalb „tief“.

04 · Die Kettenregel

Back­propagation

Wie weiß ein Gewicht tief im Netz, in welche Richtung es sich ändern soll? Das ist der Trick, der 1986 durch David Rumelhart, Geoffrey Hinton und Ronald Williams berühmt wurde.

  1. Vorwärts: Die Eingabe läuft Schicht für Schicht durch das Netz. Am Ende steht eine Vorhersage.
  2. Fehler: Vorhersage und richtige Antwort werden verglichen.
  3. Rückwärts: Der Fehler wird von hinten nach vorne durchgereicht. Jedes Neuron bekommt seinen Anteil an der Schuld, gewichtet mit der Stärke seiner Verbindung. Mathematisch ist das die Kettenregel der Ableitung.
  4. Anpassen: Jedes Gewicht macht einen kleinen Schritt gegen seinen Gradienten, genau wie beim Gradientenabstieg.
netz.js · das komplette Netz, ohne Bibliothek 
const act = { f: Math.tanh, d: a => 1 - a * a }; // Ableitung über die Aktivierung
const sigmoid = z => 1 / (1 + Math.exp(-z));

function makeNet(sizes) { // z. B. [2, 4, 4, 1]
  const W = [], B = [];
  for (let l = 1; l < sizes.length; l++) {
    const s = Math.sqrt(1 / sizes[l - 1]);
    W.push([...Array(sizes[l])].map(() =>
      [...Array(sizes[l - 1])].map(() => (Math.random() * 2 - 1) * s)));
    B.push(Array(sizes[l]).fill(0));
  }
  return { W, B };
}

function forward(net, x) {
  const A = [x];
  net.W.forEach((Wl, l) => {
    const last = l === net.W.length - 1;
    A.push(Wl.map((row, j) => {
      const z = row.reduce((s, w, i) => s + w * A[l][i], net.B[l][j]);
      return last ? sigmoid(z) : act.f(z);
    }));
  });
  return A; // alle Aktivierungen, A.at(-1)[0] ist die Vorhersage
}

function trainStep(net, x, y, lr) {
  const A = forward(net, x);
  // Sigmoid + Kreuzentropie: Fehler am Ausgang ist einfach a - y
  let delta = [A.at(-1)[0] - y];
  for (let l = net.W.length - 1; l >= 0; l--) {
    const prev = A[l].map((a, i) => l === 0 ? 0 :
      act.d(a) * delta.reduce((s, d, j) => s + d * net.W[l][j][i], 0));
    delta.forEach((d, j) => {
      net.B[l][j] -= lr * d;
      A[l].forEach((a, i) => (net.W[l][j][i] -= lr * d * a));
    });
    delta = prev;
  }
}

MerkeBackpropagation reicht den Fehler rückwärts durchs Netz und sagt jedem Gewicht, wie viel Schuld es trägt. Dann geht es einen kleinen Schritt bergab.
