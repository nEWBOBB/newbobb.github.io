01 · Statistik

Was kommt danach?

Lies einen Text und notiere für jedes Wort, welches Wort direkt danach kommt. Nach „es“ folgt in einem Märchen oft „war“, nach „war“ oft „einmal“. Zählt man das für alle Wörter, hat man eine Tabelle von Übergängen.

Teilt man die Zählungen durch die Gesamtzahl, werden daraus Wahrscheinlichkeiten: Nach „der“ kommt zu 30 % „König“, zu 20 % „Wald“ und so weiter. Mehr „Training“ braucht ein Markov-Modell nicht.

Das Besondere, und der Namensgeber: Das Modell schaut nur auf das aktuelle Wort. Alles davor ist vergessen. Der russische Mathematiker Andrei Markow hat 1913 genau so die Abfolge von Vokalen und Konsonanten in Puschkins „Eugen Onegin“ untersucht, mit Bleistift, über 20 000 Buchstaben.

MerkeEine Markov-Kette merkt sich für jeden Zustand, wie oft welcher nächste Zustand folgt. Die Vergangenheit davor spielt keine Rolle.

Klick auf ein Wort im Text. Blau markiert ist jedes Wort, das direkt danach folgt.

02 · Zustände und Übergänge

Die Kette als Graph

Man kann die Tabelle auch zeichnen: Jedes Wort ist ein Kreis, jeder mögliche Übergang ein Pfeil mit seiner Wahrscheinlichkeit. Der Satzpunkt ist ein eigener Zustand, von dem aus ein neuer Satz beginnt.

Text erzeugen heißt jetzt: Starte irgendwo und folge den Pfeilen. An jeder Kreuzung entscheidet ein Würfel, gewichtet mit den Wahrscheinlichkeiten. Das ist ein Zufallsspaziergang.

Schon mit drei kurzen Trainingssätzen entstehen Sätze, die so nie im Text standen, etwa „der Hund jagt die Maus“. Aber auch Unsinn wie „die Katze jagt die Katze jagt die Katze“. Die Kette weiß ja nicht mehr, dass sie das gerade schon gesagt hat.

MerkeText erzeugen = durch den Graphen spazieren und an jeder Kreuzung gewichtet würfeln.

Drück „Ein Schritt“ und sieh dem Würfel zu. Oder lass die Kette laufen.

03 · Gedächtnis

Der Generator

Das Vergessen ist die große Schwäche. Die Lösung: Statt nur auf das letzte Wort schaut man auf die letzten zwei oder drei. Das nennt man die Ordnung der Kette. Ein Zustand ist dann nicht mehr „jagt“, sondern „Hund jagt“.

Mehr Ordnung heißt flüssigerer Text. Aber es gibt einen Haken: Je länger der Zustand, desto seltener kommt er im Text vor. Bald gibt es für jeden Zustand nur noch eine einzige Fortsetzung, und die Kette schreibt den Originaltext einfach ab. Grün markiert sind Stellen, an denen sie wirklich eine Wahl hatte.

Statt Wörtern kann man auch Buchstaben verketten. Bei Ordnung 2 kommt Kauderwelsch heraus, bei Ordnung 5 erfundene Wörter, die verdächtig deutsch klingen.

04 · Von null an

Der ganze Code

Das ist wirklich alles. Ein Wörterbuch von Zuständen zu Listen möglicher Nachfolger. Wer ein Wort doppelt so oft gesehen hat, legt es einfach doppelt in die Liste, dann stimmt die Wahrscheinlichkeit beim Ziehen automatisch.

Und der Bezug zur modernen KI? Ein großes Sprachmodell macht im Kern dasselbe: Es sagt das nächste Wort vorher. Nur schaut es nicht auf zwei Wörter, sondern auf hunderttausende. Und statt einer Tabelle, die für jeden genauen Zustand Buch führt, benutzt es ein neuronales Netz, das auch Zustände versteht, die es so nie gesehen hat. Wie das funktioniert, zeigt Wie Sprach-KI funktioniert.

MerkeMarkov-Kette und Sprachmodell raten beide das nächste Wort. Der Unterschied ist, wie viel Kontext sie sehen und wie klug sie verallgemeinern.

Warum schreibt eine Markov-Kette mit hoher Ordnung oft wörtlich den Trainingstext ab?

function train(text, order = 2) {
  const words = text.match(/[\p{L}\d]+|[.,!?]/gu);
  const chain = new Map();
  for (let i = order; i < words.length; i++) {
    const state = words.slice(i - order, i).join(" ");
    if (!chain.has(state)) chain.set(state, []);
    chain.get(state).push(words[i]); // Duplikate = Gewicht
  }
  return chain;
}

function generate(chain, order, length = 50) {
  const states = [...chain.keys()];
  let out = states[Math.floor(Math.random() * states.length)].split(" ");
  while (out.length < length) {
    const next = chain.get(out.slice(-order).join(" "));
    if (!next) break; // Sackgasse: Zustand kam nur am Textende vor
    out.push(next[Math.floor(Math.random() * next.length)]);
  }
  return out.join(" ").replace(/ ([.,!?])/g, "$1");
}
