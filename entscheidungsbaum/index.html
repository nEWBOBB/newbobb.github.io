Entscheidungs­baum

Wie beim Spiel „Wer bin ich?“: Ein Entscheidungsbaum stellt eine Ja-Nein-Frage nach der anderen, bis die Antwort klar ist. Welche Fragen er stellt, findet er selbst heraus, mit einer einzigen Zahl: der Unreinheit.

01 · Gini-Unreinheit

Der beste Schnitt

Ein Entscheidungsbaum fragt immer nach genau einem Merkmal: „Ist x kleiner als 4?“ Auf der Fläche rechts ist das eine senkrechte oder waagrechte Linie, die die Punkte in zwei Gruppen teilt.

Ein guter Schnitt macht beide Gruppen möglichst rein, also möglichst nur eine Farbe. Gemessen wird das mit der Gini-Unreinheit: der Wahrscheinlichkeit, dass zwei zufällig gezogene Punkte aus der Gruppe verschiedene Farben haben.

Gini = 1 − Σ pₖ² pₖ ist der Anteil der Klasse k in der Gruppe. Nur eine Farbe: Gini = 0. Halb und halb: Gini = 0,5.

Die Unreinheit beider Seiten wird gewichtet mit ihrer Größe zusammengezählt. Der Baum probiert einfach jeden möglichen Schnitt aus, auf jeder Achse, und nimmt den mit der kleinsten Unreinheit. Die Kurve unter der Fläche zeigt sie für alle Positionen.

MerkeDer beste Schnitt ist der, nach dem beide Seiten am reinsten sind. Der Baum findet ihn durch stures Ausprobieren.

Wähle eine Achse und schieb den Schnitt, bis die Unreinheit möglichst klein ist.

02 · Rekursion

Ein ganzer Baum

Nach dem ersten Schnitt hat man zwei Gruppen. Für jede davon macht man genau dasselbe noch einmal: besten Schnitt suchen, teilen. Und wieder. Das hört erst auf, wenn eine Gruppe rein ist oder der Baum seine maximale Tiefe erreicht hat. Diese Idee, ein Problem mit sich selbst zu lösen, heißt Rekursion.

Am Ende zerlegt der Baum die Fläche in Rechtecke, und jedes Blatt sagt die häufigste Farbe darin vorher. Fahr mit der Maus über die Fläche, um den Weg durch den Baum zu sehen. Tippen setzt einen Punkt in der gewählten Farbe.

03 · Überanpassung

Zu tief gewachsen

Lässt man den Baum unbegrenzt wachsen, teilt er so lange, bis jedes Blatt rein ist. Auf den Trainingsdaten erreicht er dann immer 100 %. Klingt toll, ist aber eine Falle.

Echte Daten sind verrauscht: Ein paar Punkte liegen zufällig auf der falschen Seite. Ein zu tiefer Baum baut für jeden dieser Ausreißer ein eigenes kleines Kästchen. Er hat die Daten auswendig gelernt, statt das Muster zu verstehen. Auf neuen Daten, die er nie gesehen hat, wird er schlechter.

Deshalb hält man immer einen Teil der Daten zurück, die Testdaten. Die Kurve rechts zeigt beide Trefferquoten über die Tiefe. Wo sie auseinanderlaufen, beginnt die Überanpassung.

Ein beliebter Ausweg ist der Random Forest: Hunderte Bäume, jeder auf einer zufälligen Auswahl der Daten trainiert, stimmen gemeinsam ab. Ihre Fehler heben sich zum großen Teil gegenseitig auf.

Merke100 % auf den Trainingsdaten heißt nichts. Was zählt, ist die Trefferquote auf Daten, die das Modell nie gesehen hat.

Woran erkennt man die beste Tiefe für den Baum?

Zieh die Tiefe nach rechts. Gefüllte Punkte sind Training, Ringe sind Testdaten.

04 · Von null an

Der ganze Code

Der Algorithmus heißt CART (Classification and Regression Trees) und stammt von 1984. Er besteht aus drei kleinen Funktionen: Unreinheit messen, besten Schnitt suchen, rekursiv wachsen.

Entscheidungsbäume haben einen großen Vorteil gegenüber neuronalen Netzen: Man kann sie lesen. Jede Vorhersage lässt sich als Kette von Fragen erklären. Deshalb werden sie gern dort eingesetzt, wo Entscheidungen nachvollziehbar sein müssen, etwa bei Krediten oder in der Medizin.

MerkeMessen, bester Schnitt, rekursiv weiter: Mehr ist ein Entscheidungsbaum nicht.

function gini(points) {
  const counts = {};
  points.forEach(p => counts[p.c] = (counts[p.c] || 0) + 1);
  return 1 - Object.values(counts)
    .reduce((s, n) => s + (n / points.length) ** 2, 0);
}

function bestSplit(points) {
  let best = { score: Infinity };
  for (const f of ["x", "y"]) {
    for (const p of points) {
      const thr = p[f];
      const L = points.filter(q => q[f] <= thr);
      const R = points.filter(q => q[f] > thr);
      if (!L.length || !R.length) continue;
      const score = (L.length * gini(L) + R.length * gini(R)) / points.length;
      if (score < best.score) best = { f, thr, L, R, score };
    }
  }
  return best;
}

function grow(points, depth, maxDepth) {
  const counts = {};
  points.forEach(p => counts[p.c] = (counts[p.c] || 0) + 1);
  const pred = Object.keys(counts)
    .reduce((a, b) => counts[a] >= counts[b] ? a : b);
  if (depth >= maxDepth || gini(points) === 0) return { pred };
  const s = bestSplit(points);
  if (!s.L) return { pred };
  return { f: s.f, thr: s.thr,
    left: grow(s.L, depth + 1, maxDepth),
    right: grow(s.R, depth + 1, maxDepth) };
}

function predict(node, p) {
  while (!("pred" in node))
    node = p[node.f] <= node.thr ? node.left : node.right;
  return node.pred;
}
