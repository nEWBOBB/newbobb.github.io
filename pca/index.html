Haupt­komponenten­analyse

Daten haben oft viel zu viele Spalten. Die PCA findet die wenigen Richtungen, in denen wirklich etwas passiert, und wirft den Rest weg. Klingt nach Magie, ist aber nur geschickt gedreht.

01 · Die Idee

Die beste Richtung

Stell dir vor, du misst bei vielen Menschen Körpergröße und Schuhgröße. Die beiden Werte hängen stark zusammen: Wer groß ist, hat meist auch große Füße. Eigentlich steckt in den zwei Spalten fast nur eine Information, so etwas wie „wie groß ist die Person insgesamt“.

Die PCA sucht genau diese Richtung. Sie legt eine Achse durch die Punktwolke und projiziert jeden Punkt darauf, wie einen Schatten. Dann misst sie, wie weit die Schatten auseinanderliegen, also ihre Varianz.

Die Achse mit der größten Varianz behält am meisten von den Unterschieden zwischen den Punkten. Sie heißt erste Hauptkomponente. Die zweite steht senkrecht darauf und bekommt den Rest.

MerkeDie erste Hauptkomponente ist die Richtung, in der die Daten am meisten streuen. Wer nur sie behält, verliert am wenigsten.

Dreh die Achse und finde die Richtung, in der die Schatten am weitesten auseinanderliegen. Punkte kannst du setzen, ziehen und antippen zum Löschen.

02 · Die Mathematik

Kovarianz und Eigen­vektoren

Man muss nicht alle Winkel durchprobieren. Alles, was man braucht, steckt in einer kleinen Tabelle, der Kovarianzmatrix. Dafür zieht man zuerst von jeder Spalte ihren Mittelwert ab, sodass die Wolke um den Nullpunkt liegt.

C = (1/n) · Xᵀ · X Auf der Diagonale steht die Varianz jeder Spalte, daneben die Kovarianz: Wachsen beide Spalten gemeinsam, ist sie positiv; läuft eine hoch, wenn die andere runter geht, negativ.

Die Hauptkomponenten sind die Eigenvektoren dieser Matrix. Ein Eigenvektor ist eine Richtung, die von der Matrix nicht gedreht, sondern nur gestreckt wird. Der Streckfaktor, der Eigenwert, ist genau die Varianz in dieser Richtung.

Dreht man die Wolke so, dass die Eigenvektoren auf den Achsen liegen, sind die neuen Spalten unkorreliert: Die Kovarianz daneben wird null. Das ist die ganze PCA.

MerkePCA = Kovarianzmatrix ausrechnen, ihre Eigenvektoren finden, die Daten in dieses neue Koordinatensystem drehen.

03 · Von Hand gerechnet

Power-Iteration

Wie findet ein Computer Eigenvektoren, ohne Bibliothek? Mit einem verblüffend einfachen Trick: Nimm irgendeinen Pfeil, multipliziere ihn mit der Matrix, mach ihn wieder auf Länge 1. Wiederhole.

Bei jeder Multiplikation wird der Anteil in Richtung der größten Streuung am stärksten verlängert. Nach ein paar Runden zeigt der Pfeil von ganz allein auf die erste Hauptkomponente. Für die zweite zieht man die erste aus der Matrix heraus (Deflation) und macht dasselbe noch einmal.

pca.js · ohne Bibliothek
function covariance(X) { // X: Zeilen = Punkte
  const n = X.length, d = X[0].length;
  const mean = Array(d).fill(0);
  X.forEach(r => r.forEach((v, j) => mean[j] += v / n));
  const C = [...Array(d)].map(() => Array(d).fill(0));
  for (const r of X)
    for (let i = 0; i < d; i++)
      for (let j = 0; j < d; j++)
        C[i][j] += (r[i] - mean[i]) * (r[j] - mean[j]) / n;
  return C;
}

function powerIteration(C, steps = 100) {
  let v = C.map(() => Math.random());
  for (let s = 0; s < steps; s++) {
    const w = C.map(row => row.reduce((a, c, j) => a + c * v[j], 0));
    const len = Math.hypot(...w);
    v = w.map(x => x / len);
  }
  const Cv = C.map(row => row.reduce((a, c, j) => a + c * v[j], 0));
  const lambda = Cv.reduce((a, x, i) => a + x * v[i], 0);
  return { v, lambda };
}

function pca(X, k) {
  let C = covariance(X);
  const comps = [];
  for (let c = 0; c < k; c++) {
    const { v, lambda } = powerIteration(C);
    comps.push({ v, lambda });
    // Deflation: gefundene Richtung aus C entfernen
    C = C.map((row, i) => row.map((x, j) => x - lambda * v[i] * v[j]));
  }
  return comps;
}

04 · Dimensionen reduzieren

Von 3D nach 2D

Richtig nützlich wird die PCA, wenn es viele Spalten gibt. Hier sind drei Gruppen von Punkten im Raum, die fast in einer schiefen Ebene liegen. Links kannst du die Wolke drehen. Rechts steht das, was die PCA daraus macht: die beiden Hauptkomponenten als neue Achsen. Die Gruppen sind sofort sauber zu erkennen, obwohl eine ganze Dimension weggeworfen wurde.

Genau so werden Bilder, Gene oder Wörter mit hunderten Spalten auf zwei Dimensionen gebracht, damit Menschen sie anschauen können.

Zieh links, um die 3D-Wolke zu drehen. Mit dem Regler machst du die Ebene dicker und siehst, wie die dritte Komponente wichtiger wird.
